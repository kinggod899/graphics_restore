# 恢复游戏画质

把「设置 → 画面」里的帧率、渲染精度、抗锯齿，以及「设置 → 其他」里的字体选项改回「降低游戏画质」动手之前的档位。

## 运行前提

- **必须以管理员权限启动一条龙**。游戏进程是管理员权限，普通权限的程序点不动游戏里的任何按钮。
- 游戏语言是简体中文。界面识别按中文文字匹配。

## 一条龙里的位置

排序值是 2900，写在 `factory.py` 里（`const.py` 和 `plugin.json` 都不放这个字段）。排在最后（通知应用 3000 之前），把画质还原给玩的人用。

本插件覆盖了 `create_run_record()` 返回 `None`，一条龙每次运行都会执行它。

装好后它默认是**未启用**状态，需要到一条龙的运行列表里手动勾上。

## 目标档位从哪来

默认：

1. 优先读 `plugin_data/graphics_low/graphics_low_snapshot.yml`（「降低游戏画质」记下的全局快照，不分实例）里的 `original_fps` / `original_render_scale` / `original_antialias` / `original_font`。旧版本把快照写在 `config/graphics_low_snapshot.yml`，新位置找不到时会回落到那里。
2. 缺哪项就用本插件的兜底档位补（字体有一条例外，见下）。

打开设置页里的「只用兜底档位」后，上面这条路直接不走，每次都按兜底档位恢复。适合这几种情况：

- 你自己手动定死了想要的画质，不想被「降低游戏画质」当时的状态影响。
- 「降低游戏画质」记下的原始档位已经不准了（比如你在游戏里改过画质，但没清空记录）。
- 只想装恢复画质这一个插件，把画质固定调成某个档。

在一条龙的运行列表里点本应用右侧的设置按钮，会从右侧滑入一页独立设置界面，四个兜底档位各一个下拉框，页面底部同时显示「降低游戏画质」记下的当前原始档位。

| 设置项 | 默认值 |
| --- | --- |
| 只用兜底档位 | 关 |
| 兜底帧率 | 60 |
| 兜底渲染精度 | 1.0 |
| 兜底抗锯齿 | SMAA |
| 兜底字体 | 全局细体 |

设置页下方会写清这次实际会用哪套值：开着就显示兜底档位，关着就显示读到的原始档位。开关一动，那行说明立刻跟着变。

没装「降低游戏画质」、或者它从没跑成功过，就全部用兜底档位。

字体有一个例外：快照里**有**记录、但没有 `original_font` 时，本次不碰字体。那是旧版本降画质插件记下的快照，当时它还不会改字体，说明字体没被动过，落到兜底值反而会把用户自己选的字体覆盖掉。等降画质插件再跑一次补记上 `original_font`，之后就会正常恢复。

这不是通过 import 降画质插件的代码拿到的：两个插件分开安装，只装恢复画质时 import 会直接崩。这里按约定路径直接打开那个文件读，文件不存在读到的就是空串，自然落到兜底档位。

## 执行链路

传送「录像店 / 房间」 → 回到大世界 → 点左上角「菜单」开暂停菜单 → 点底部「设置」 → 确认停在「画面」页签 → 确定目标档位 → 恢复帧率 → 恢复渲染精度 → 恢复抗锯齿 → 切到「其他」页签 → 恢复字体 → 连点两次返回回到大世界。

字体那一段在没有目标字体时会整段跳过，连页签都不切。

## 坐标说明

`screen.py` 里的坐标和「降低游戏画质」插件里的那份是同一批实测值。两个插件各自是独立的插件根，导入时互不依赖，所以这份坐标在两个插件里各存了一份，改坐标要两边一起改。「其他」页的页签点击点 (206, 610) 和字体行（行中心 479）也一样，两个插件各维护一份。
